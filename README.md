# 🔐 Landing Page - Cerrajero Profesional

Landing page desarrollada con **Astro** enfocada en la captación de clientes para servicios de cerrajería, con contacto directo vía WhatsApp para maximizar conversiones.

---

## 🧩 Descripción del proyecto

Este proyecto consiste en una página web optimizada para un cerrajero, donde se presentan sus servicios principales de forma clara y accesible, facilitando el contacto inmediato con potenciales clientes.

El enfoque principal fue:

* Generar confianza en el usuario
* Mostrar servicios de forma clara
* Reducir fricción en el contacto (CTA directo a WhatsApp)

---

## ⚙️ Stack tecnológico

* Astro (renderizado estático y alto rendimiento)
* Tailwind CSS (estilos y diseño responsive)
* JavaScript (interacciones y lógica de UI)

---

## 🎯 Características principales

* 🧱 Landing page optimizada para conversión
* 📱 Diseño completamente responsive
* ⚡ Carga rápida (optimización de rendimiento con Astro)
* 📲 Botón de contacto directo a WhatsApp
* 🧭 Navegación clara y enfocada en servicios

---

## 🧠 Enfoque técnico

* Arquitectura basada en componentes reutilizables
* Optimización de assets para mejorar el rendimiento
* Separación clara entre layout, componentes y páginas

---

## 📁 Estructura del proyecto

```text
/
├── public/             # Archivos estáticos
├── src/
│   ├── components/     # Componentes reutilizables
│   ├── layouts/        # Layout principal
│   ├── pages/          # Rutas del sitio
│   └── styles/         # Estilos globales
│   └── types/          # Tipo de datos globales
└── package.json
```

---

## 🚀 Instalación y uso

```bash
npm install
npm run dev
```

Para generar el build de producción:

```bash
npm run build
```
